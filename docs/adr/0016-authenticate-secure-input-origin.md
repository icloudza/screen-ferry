# 0016 独立认证安全桌面输入来源

状态：已采纳（维护者授权实施下一阶段输入来源认证）

## 边界

普通用户后台、用户配对文件、本机管道的报文均不构成 UAC 输入授权。管理员另行登记远端设备证书指纹和 P-256 公钥，按被控端用户 SID 隔离。
记录位于固定的 HKLM\Software\ScreenFerry\SecureInput 注册表策略中，只允许 SYSTEM/管理员修改；不改变用户运行时数据目录和配置 schema。
注册表访问与权限校验属于 Windows 平台适配器；服务应用只解析管理参数，不引入 L2 互相依赖。

## 输入证明

- 控制端从自己的设备身份导出公开授权码，管理员通过可信渠道核对后登记；普通配对不自动授予此权限。
- 普通后台只能转发代理生成的随机挑战和远端签署的输入。代理不接受未签署的特权按键、移动、锁定键或隐藏光标请求。
- 签名使用已有设备 P-256 私钥和 ring ECDSA P-256/SHA-256，固定 64 字节签名；域分离的签名正文包含协议标识、随机挑战、连续序号和完整定长动作正文。
- 每条管道绑定一个已授权的远端。代理生成挑战，最多有效 1 秒，定期轮换且有界保留。序号在同一管道中从 1 连续增加，轮换挑战不重置序号。
- 只有验证通过的远端输入或签署保活才延长 1.5 秒输入租约。本机 Check 不续期，断联、过期、验签失败或撤销授权都会释放状态。
- 签署动作包括进入、退出、键鼠及保活。定位后点击、进入时锁定键同步、退出时释放和光标操作在代理中执行，不能由普通后台拆改。
- 每次输入和空闲检查都重查授权，撤销后当前会话也失效。新管道使用新随机挑战，旧证明不能跨重连重用。
- 控制端只签署自己产生的输出事件及保活，不提供为客户端指定动作签名的消息接口。

## 兼容和开放

签署输入是新增消息，以能力协商选择，不认识它的旧版本照常连接。未获 UAC 授权的普通配对设备继续使用普通权限输入。
服务随正式安装包提供、安装时默认不选（见 ADR 0015 的实施状态）；Windows 安装器、安全桌面及故障场景按清单做实机验收。
本机制不抵御管理员、SYSTEM 或已授权控制端自身被攻陷，也不能阻止普通后台丢弃输入造成拒绝服务。
签署动作正文仍在普通后台中可见，不提供防后台读取按键的端到端保密；生产开放前仍需评估凭据输入场景。

实现参考：[ring 的 ECDSA 签名接口](https://docs.rs/ring/0.17.14/ring/signature/struct.EcdsaKeyPair.html)。
