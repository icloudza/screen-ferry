# ScreenFerry 0.2.0

## 简体中文

### 新增

- Windows 安装时可以勾选“允许已配对的电脑操作 Windows 权限提示（UAC）”：管理员给控制端授权后，另一台电脑就能操作权限提示、锁屏和以管理员身份运行的程序。默认不选
- 被控的那台用自己的鼠标或触控板把文件拖到屏幕边缘，也能发给另一台

### 改进

- Windows 上遇到权限提示、锁屏或管理员窗口时，光标自动回到控制端，连接不断，剪贴板和文件照常
- 设备的边缘切换延迟对进入对方和回到本机都生效
- 新旧版本可以直接互连，不用两台同时升级

### 修复

- 接了大小不一的几块显示器时，光标进出按贴着边缘的那块屏幕对齐，不再跳到别的屏幕上
- 剪贴板连接卡住时，键鼠不再跟着卡住
- 被控端一时松不开的按键会在恢复后补上，不再卡键

## English

### New

- The Windows installer has a new option, “Allow paired computers to control Windows permission prompts (UAC)”: once an administrator authorizes the controller, the other computer can operate permission prompts, the lock screen and programs running as administrator. Off by default
- Drag files to a screen edge with the controlled computer’s own mouse or trackpad to send them to the other one

### Improved

- On Windows, when a permission prompt, the lock screen or an administrator window appears, the cursor returns to the controller; the connection stays up and clipboard and files keep working
- A device’s edge-switch delay now applies both when entering it and when coming back
- Old and new versions connect to each other directly, so you don’t have to update both computers at once

### Fixed

- With several displays of different sizes, the cursor now enters and leaves aligned with the display at the edge instead of jumping to another one
- Keyboard and mouse no longer freeze when the clipboard connection stalls
- Keys the controlled computer couldn’t release right away are released once it recovers, so they no longer get stuck
